# Bnyan (بنيان) 🏗️ - MVP Structure & Status
### منصة استثمار عقاري سعودية متطورة

بنيان هي منصة سعودية رائدة في مجال الاستثمار العقاري الرقمي، تهدف إلى توفير فرص استثمارية آمنة وموثوقة للمستثمرين في المملكة العربية السعودية بما يتوافق مع رؤية المملكة 2030 وتوجيهات هيئة السوق المالية (CMA).

---

## 🚀 الهيكل العام للمشروع وحالة الإنجاز (Project Status)

فيما يلي المخطط الشامل للنسخة الأولية للمشروع (MVP) مع توضيح ما تم إنجازه (✅) وما هو قيد التطوير أو مجدول (⏳):

### 👤 أولًا: بوابة المستثمر (Investor Side)
- [x] **1️⃣ الصفحة الرئيسية (Home/Onboarding):** Hero Section، كيف تعمل المنصة، CTA للاستثمار.
- [x] **2️⃣ تسجيل الدخول (Login):** تسجيل الدخول باستخدام البريد/الجوال.
- [x] **3️⃣ إنشاء حساب (Register):** جمع البيانات الأساسية (الاسم، الهوية، الجوال، الخ).
- [x] **4️⃣ نظام التحقق من الهوية (KYC):** 
  - محاكاة احترافية للتحقق في 3 ثوانٍ فقط.
  - دعم الحالات: Pending, Approved, Rejected.
- [x] **5️⃣ استكشاف المشاريع (Projects List):** بطاقات المشاريع، نسب التمويل.
- [x] **6️⃣ تفاصيل المشروع (Project Details):** صور، عوائد، مستندات قانونية، عدد المستثمرين.
- [x] **7️⃣ صفحة الاستثمار (Invest):** إدخال المبلغ، الموافقة على المخاطر.
- [ ] **8️⃣ صفحة الدفع (Payment):** اختيار وسيلة الدفع (Mada, Apple Pay, Visa)، محاكاة المعالجة.
- [ ] **9️⃣ نجاح الاستثمار (Success):** رقم العملية، تحميل الشهادة.
- [x] **🔟 لوحة المستثمر (Dashboard):** إجمالي الاستثمارات، المحفظة.
- [ ] **1️⃣1️⃣ استثماراتي (My Investments):** تتبع حالة المشاريع والأرباح.
- [ ] **1️⃣2️⃣ الأرباح (Profits):** الأرباح المستلمة والمتوقعة والجداول الزمنية.
- [ ] **1️⃣3️⃣ المحفظة المالية (Wallet):** الرصيد، الإيداع، السحب (IBAN).
- [ ] **1️⃣4️⃣ الإشعارات (Notifications):** تنبيهات الاستثمار وتحديثات المشاريع.
- [ ] **1️⃣5️⃣ الملف الشخصي (Profile):** تعديل البيانات وحالة KYC.

### 🏢 ثانيًا: بوابة المطور العقاري (Developer Portal)
- [x] **1️⃣ لوحة تحكم المطور (Developer Dashboard):** عدد المستثمرين، وحالة التمويل.
- [ ] **2️⃣ إضافة مشروع (Add Project):** رفع التفاصيل، العوائد، الصور، والمستندات.
- [ ] **3️⃣ إدارة المشاريع (Manage Projects):** التعديل، الحذف، ومتابعة التمويل.

### 🛡️ ثالثًا: لوحة الإدارة (Admin Panel)
- [ ] **1️⃣ لوحة الإدارة (Admin Dashboard):** إحصائيات عامة للمستخدمين، الاستثمارات، وحالة التمويل.
- [ ] **2️⃣ إدارة المستثمرين (Manage Users):** مراجعة حسابات KYC والاعتماد اليدوي.
- [ ] **3️⃣ إدارة المشاريع (Manage Projects):** الموافقة على نشر المشاريع وإغلاق التمويل.
- [ ] **4️⃣ إدارة الاستثمارات (Manage Investments):** تتبع العمليات والمراقبة المالية (Escrow).
- [ ] **5️⃣ سجلات التدقيق (Audit Logs):** سجل شامل لجميع العمليات والتحويلات.

### 💰 رابعًا: الوحدات المالية (Financial Modules)
- [ ] **1️⃣ نظام الضمان (Escrow Module):** تتبع الأموال المحتجزة للمشاريع (متطلب هام لـ CMA).
- [ ] **2️⃣ حاسبة العوائد (ROI Calculator):** حساب العوائد المتوقعة بناءً على مبلغ الاستثمار والمدة.
- [ ] **3️⃣ نظام المحفظة (Wallet System):** إدارة الأرصدة وسجلات السحب والإيداع.

### 🔐 خامسًا: وحدات الأمان والامتثال (Security & Compliance)
- [x] **1️⃣ وحدة اعرف عميلك (KYC Module):** تتبع حالة التحقق وعرض شارات الأمان (Auth Verified).
- [ ] **2️⃣ الإقرار بالمخاطر (Risk Disclosure):** الموافقة القانونية للمستثمرين.
- [ ] **3️⃣ الشروط والخصوصية (Terms & Privacy):** صفحات الشروط، سياسة الخصوصية، والإفصاح عن المخاطر.

### ⚙️ سادسًا: منطق المحاكاة (Simulation Logic)
- [x] **تخزين البيانات الأساسي:** الاعتماد على LocalStorage و Services لمحاكاة الجلسات وKYC.
- [ ] **تكامل قواعد البيانات:** الانتقال إلى Firebase / Supabase لإدارة البيانات بشكل فعلي.

## 🧠 مسار المستخدم النموذجي (User Flow)
**Register** ➔ **KYC Verification** ➔ **Browse Projects** ➔ **Invest** ➔ **Payment** *(Pending)* ➔ **Success** *(Pending)* ➔ **Dashboard**
